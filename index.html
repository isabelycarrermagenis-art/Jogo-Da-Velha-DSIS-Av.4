Super Jogo da Velha com IA 🤖

Este projeto foi desenvolvido em Python utilizando a biblioteca PyQt6 para a interface gráfica e o algoritmo Minimax para a Inteligência Artificial.

⚠️ Nota Técnica: Como o PyQt6 gera aplicações nativas de Desktop, o jogo não pode ser renderizado diretamente aqui no navegador via GitHub Pages.

Para testar o jogo, faça o download dos arquivos fonte no repositório e execute python jogo_da_velha_ia.py no seu terminal.
